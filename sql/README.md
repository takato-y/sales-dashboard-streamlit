# sql/

売上の集計（指標・月次推移・ABC 分析・内訳）は、このフォルダの SQL で行います。Python は明細の読み込み・検証と、条件の書き込み・ビューの読み出しだけを担当します。

| ファイル | 内容 | 実行 |
|---|---|---|
| `001_schema.sql` | 表の定義（SQLite） | 自動テストで毎回適用 |
| `002_views.sql` | 指標・月次推移・ABC 分析・内訳のビュー（SQLite） | 自動テストで毎回適用 |
| `procedures/load_sales.sql` | 取込用の一時置き場から本表へ移す処理 | 読み込みのたびに実行 |
| `sqlserver/001_schema.sql` | 表の定義（SQL Server 版） | **未実行** |
| `sqlserver/002_functions.sql` | 月次推移・ABC 分析の関数（SQL Server 版） | **未実行** |

## 版の管理

- `NNN_名前.sql` の番号順に、まだ適用していないものだけを適用し、適用した番号を `schema_version` 表に記録します（`sales_dashboard/db.py` の `SalesDB.migrate()`）。
- 適用済みのファイルは書き換えません。表やビューを変えるときは `003_*.sql` のように新しい番号のファイルを足します。

## 主なビュー

| ビュー | 内容 |
|---|---|
| `v_dim_line` | 担当者・カテゴリ・地域で絞り込んだ明細（期間は問わない） |
| `v_filtered_line` | すべての条件で絞り込んだ明細 |
| `v_monthly_sales` | 月ごとの売上・粗利・粗利率・前年同月比・前月比 |
| `v_kpi` | 期間の指標（1 行） |
| `v_abc_customer` / `v_abc_product` | ABC 分析 |
| `v_breakdown` | 地域別・担当者別・商品カテゴリ別 |

## SQL Server へ移すとき

`sqlserver/` に主要な表と関数の T-SQL 版を置いています。SQL Server の実行環境で試していないため、**未実行**です。SQLite 版との主な違いは次のとおりです。

| 項目 | SQLite 版 | SQL Server 版 |
|---|---|---|
| 絞り込み条件の受け渡し | `w_cond_*` 表に書き、ビューで読む（1 画面につき 1 つのメモリ上のデータベースなので衝突しない） | 引数で受け取るインライン表値関数（複数の利用者が同時に使うため、共有の条件表は使わない） |
| 期間内の全月 | 再帰 CTE（`v_month_seq`） | 月の一覧表 `m_month`（関数の中では再帰の上限を変えられないため） |
| 金額 | 取込時に `INSERT … SELECT` で計算 | 計算列（`PERSISTED`） |
| 文字列・数値の型 | `TEXT` / `REAL` | `NVARCHAR` / `DECIMAL(18,2)`（金額の小数の誤差を避ける） |
| 年月 | `substr()` と `printf()` | `CONVERT(CHAR(7), …, 126)` と計算列 |
| 担当者などの複数選択 | 条件表に複数行 | 1 つだけ（複数にするには表値パラメータに置き換える） |
