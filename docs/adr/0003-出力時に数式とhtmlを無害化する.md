## 背景

得意先名・商品名は利用者が読み込んだファイルに由来する。`=HYPERLINK(...)` のような文字列がそのまま Excel に書かれると、開いた人の PC で数式として動く（CSV・数式インジェクション）。印刷用ページでは `<script>` などが HTML として解釈されるおそれがある（REQ-011）。

## 決定

- Excel 出力では、文字列が `=` `+` `-` `@` タブ・復帰（CR）・改行（LF）のいずれかで始まる場合、先頭に `'`（アポストロフィ）を付けて文字列として書く。あわせてセルの型を文字列に固定する
- 数値（金額・数量）は数値のまま書く。マイナスの金額は数値なので対象外
- 印刷用ページでは、表示するすべての文字列を HTML の特殊文字として変換（エスケープ）してから埋め込む。外部のスクリプト・画像は読み込まない
- 読み込み時には元の値を変えない（画面上は元の文字列のまま表示する）。無害化は出力時だけに行う

## 結果

- 先頭に `'` が付いた得意先名は、Excel 上ではその記号を含んだ文字列として見える。誤解を避けるため README に記載する
- 無害化の処理は `sales_dashboard/export.py` にまとめ、自動テストで確認する
