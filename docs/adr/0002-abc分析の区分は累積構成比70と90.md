## 背景

ABC 分析（REQ-005）の区切りには、70%・90% や 80%・95% など複数の流儀がある。また「しきい値ちょうどをまたぐ 1 件」をどちらに入れるかで結果が変わる。

## 決定

- 売上金額の多い順に並べ、**その 1 件より前までの累積構成比**で区分する
  - 前までの累積が 70% 未満 → A
  - 前までの累積が 70% 以上 90% 未満 → B
  - それ以外 → C
- 売上金額が 0 以下（返品が上回った得意先など）は、順位にかかわらず C とする
- 同じ売上金額のときはコードの昇順で並べる（結果を毎回同じにするため）

「前までの累積」で判定するのは、1 件で 70% を超える大口の得意先が B になることを避けるためである。

## 結果

- 区切りの値は `sales_dashboard/analysis.py` の定数にまとめ、変更しやすくする
- 指標の定義として基本設計書と README に計算式を記載する
