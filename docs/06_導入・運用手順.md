## 1. 前提

| 項目 | 内容 |
|---|---|
| Python | 3.12（動作を確かめたのは 3.12.3） |
| OS | Linux（WSL2）で確認。Windows・macOS では未確認 |
| ネットワーク | 導入時にライブラリを取得するときだけ必要。使うときは不要 |
| 利用範囲 | 認証がないため、利用者自身の PC で使う。社内ネットワークに公開しない |

## 2. 導入

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows の場合は .venv\Scripts\activate
pip install -r requirements.txt
```

テストと画面の撮影も行う場合は `requirements-dev.txt` を使い、Playwright のブラウザを入れます。

```bash
pip install -r requirements-dev.txt
playwright install chromium
```

## 3. 起動と終了

```bash
streamlit run app/streamlit_app.py --server.address 127.0.0.1
```

- ブラウザで `http://127.0.0.1:8501` を開きます（ポートは起動時の表示に従います）。
- 終了は起動した端末で Ctrl＋C を押します。読み込んだデータはメモリ上だけにあり、終了すると消えます。
- `.streamlit/config.toml` でも待ち受けアドレスを `127.0.0.1` にしています。`--server.address 0.0.0.0` のように変えると社内の他の PC から開けるようになりますが、認証がないため行わないでください。

## 4. 毎月の使い方

1. 販売管理システムから売上明細を CSV（または Excel）で出力します。列は `docs/04_入力データ仕様.md` のとおりです。
2. 画面のサイドバーで「ファイルを読み込む」を選び、複数月のファイルをまとめて選びます。
3. 画面上部に黄色の帯が出た場合は「取込結果」タブで除外した行と理由を確かめ、元のファイルを直して読み込み直します。除外した行は CSV で保存できます。
4. 期間・担当者・商品カテゴリ・地域を選び、各タブで確かめます。
5. 「出力」タブで Excel または印刷用ページを保存します。印刷用ページはブラウザで開き、印刷で「PDF に保存」を選びます。

## 5. 架空データ・サンプル

```bash
python scripts/generate_data.py                 # data/generated/ に月別 CSV を 24 本（2024-01〜2025-12）
python scripts/generate_data.py --format xlsx   # 月別 Excel
python scripts/generate_data.py --samples       # samples/ を作り直す
```

`data/generated/` はリポジトリに含めません（`.gitignore`）。

## 6. テストと画面の撮影

```bash
python -m pytest -v            # 全テスト（10 万行の性能テストを含む。計測値は -s で表示）
python -m pytest -m perf -s    # 性能テストだけ
```

画面の撮影は、別の端末で `--server.port 8599` を付けて画面を起動してから行います。

```bash
python scripts/take_screenshots.py --work 作業用フォルダ
```

`docs/images/` に 6 枚の画像を保存し、作業用フォルダにダウンロードした Excel・印刷用ページと、その PDF を保存します。画面に例外が表示された場合は撮影を中止します。

## 7. 集計の SQL を変えるとき

1. `sql/` に新しい番号のファイル（例：`003_abc_threshold.sql`）を作ります。適用済みのファイル（`001`・`002`）は書き換えません。
2. ビューを変える場合は、新しいファイルに `DROP VIEW` と `CREATE VIEW` を書きます。
3. `python -m pytest` で、標準ライブラリの計算との突き合わせ（TC-020〜TC-034）が通ることを確かめます。
4. 基本設計書の「指標の定義」とテーブル定義書のビュー一覧を更新します。

## 8. 困ったとき

| 症状 | 確認すること |
|---|---|
| 「必須の列がありません」と出る | 1 行目の列名が入力データ仕様と同じか（前後の空白は無視される） |
| 「文字コードを判定できません」と出る | CSV を UTF-8 または Shift_JIS で保存し直す |
| 指標が「—」になる | 前年同月・前月のデータを読み込んでいるか。売上が 0 以下でないか |
| Excel の得意先名の先頭に「'」が付いている | 名称が「=」「+」「-」「@」などで始まっている。数式として動かないように付けたもの（ADR-0003） |
| 画面に「エラーが発生しました」とだけ出る | 起動した端末に詳細が出ている。画面にはファイルの場所などを出さない設定にしている |
