## 1. 概要

- 自動テスト（pytest）：TC-001〜TC-093・TC-100 のうち 2 章の表に挙げたもの。`python -m pytest -v` で実行する（性能の計測値を表示するには `-s` を付ける）
- 手動（画面の操作・目視）：TC-080〜TC-088。画面の撮影は `scripts/take_screenshots.py`（Playwright・ヘッドレスの Chromium）で行った
- 実施結果は実際に実行した結果だけを書く。実行していないものは「未実施」とする
- 指標・ABC 分析・内訳の期待値は、pandas も SQL も使わず、標準ライブラリの `csv` で CSV を読んで素朴に計算した値（TC-020・TC-021・TC-030・TC-034）
- テストデータはすべて架空（`sales_dashboard/generator.py` で生成、または `tests/helpers.py` で数行を組み立てる）
- 欠番：`TC-032`（得意先名は最新の名称を使う）は、名称の決め方を SQL の取込処理に移したため TC-045 に統合した
