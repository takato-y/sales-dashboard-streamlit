## 1. 業務の背景と目的

想定する業務は、食品・日用品などを扱う架空の小規模卸売会社（以下「当社」）の月次の売上分析です。当社では販売管理システムから毎月の売上明細を CSV で出力し、経理担当者が Excel に貼り付けて、関数とピボットテーブルで売上・粗利を集計しています。集計結果は月初の営業会議で使います。

本システムの目的は、次の 3 点です。

- 売上明細を読み込むだけで、会議で使う指標とグラフがそろう状態にする
- 明細の誤り（日付の書式違い、数量の空欄、同じ明細の二重計上）を集計前に見つけ、理由とともに示す
- 担当者・商品カテゴリ・期間を切り替えた集計を、その場で作れるようにする

## 2. これまでの課題

| No | 課題 | 影響 |
|---|---|---|
| 1 | 毎月、複数月分の CSV を手で貼り合わせている | 貼り付け範囲の誤りや、同じ月を二重に貼る誤りが起きる |
| 2 | 明細の誤りに集計後まで気付かない | 日付が文字列のままの行や数量が空欄の行が、集計から黙って漏れる |
| 3 | 前年同月比・前月比を手作業の関数で出している | 対象月をずらすたびに参照範囲を直す必要があり、担当者に依存する |
| 4 | 担当別・カテゴリ別の集計は、依頼があるたびにピボットを作り直している | 会議中の質問にその場で答えられない |
| 5 | 会議資料の体裁を毎月整えている | 集計とは別に作業時間がかかる |

## 3. 機能要件

| ID | 要件 | 優先度 |
|---|---|---|
| REQ-001 | 複数月分の売上明細（CSV・Excel）をまとめて読み込める。サンプルデータでも試せる | 必須 |
| REQ-002 | 読み込み時に明細を検証し、誤りのある行は集計から除外したうえで、ファイル名・行番号・理由を一覧で示す | 必須 |
| REQ-003 | 売上・粗利・粗利率・前年同月比・前月比を指標として表示する | 必須 |
| REQ-004 | 月ごとの売上・粗利の推移を、前年の同じ月と並べてグラフで表示する | 必須 |
| REQ-005 | 得意先別・商品別の上位を表示し、売上の累積構成比で A・B・C に分類する（ABC 分析） | 必須 |
| REQ-006 | 地域別・担当者別の売上・粗利を表示する | 必須 |
| REQ-007 | 期間・担当者・商品カテゴリ（加えて地域）で絞り込める。絞り込みはすべての指標・グラフ・表に反映される | 必須 |
| REQ-008 | 絞り込んだ結果の集計を Excel ファイルとして出力できる | 必須 |
| REQ-009 | 絞り込んだ結果の集計を、ブラウザの印刷機能で PDF に保存しやすい体裁で出力できる | 必須 |
| REQ-010 | 動作確認・デモ用に、2 年分の架空の売上明細（季節による増減あり）を生成できる | 必須 |
| REQ-011 | 出力する Excel・印刷用ページに、読み込んだファイル由来の文字列（得意先名・商品名など）が数式や HTML として解釈されないようにする | 必須 |

## 4. 非機能要件

| ID | 区分 | 要件 |
|---|---|---|
| REQ-101 | 性能 | 10 万行の明細（CSV）を、読み込み・検証・集計（指標・月次推移・ABC 分析・地域別・担当者別）まで 10 秒以内で処理できる。Excel（.xlsx）は読み込みに時間がかかるため、参考値として測定する |
| REQ-102 | データの扱い | 読み込んだファイルはブラウザと同じ PC の中だけで処理し、外部へ送信しない。サーバ側のディスクにも保存しない。画面は同じ PC（127.0.0.1）からのみ開ける |
| REQ-103 | 操作性 | ファイルを選ぶ・絞り込みを選ぶ・出力ボタンを押す、の 3 種類の操作だけで使える。誤りのある行があっても処理を止めず、件数を画面上部に示す |

## 5. 対象外

- 利用者の認証・権限管理（ローカル専用で使う前提のため）
- 販売管理システムとの自動連携（CSV の出力は従来どおり手作業で行う）
- 返品・値引の伝票の個別処理（数量がマイナスの行は返品としてそのまま合算する）
- 予算・目標との比較、売上予測
- 複数人での同時利用、インターネットへの公開
- 税込・税抜の換算（明細の単価は税抜で入っている前提）

## 6. 用語

| 用語 | 意味 |
|---|---|
| 明細 | 売上伝票の 1 行。1 つの伝票に複数の明細が含まれる |
| 粗利 | 売上金額から原価金額を引いた額 |
| ABC 分析 | 売上の多い順に並べ、累積の構成比で重要度を A・B・C に分ける方法 |
| 絞り込み | 期間・担当者などの条件で、集計の対象にする明細を限定すること |
